## Princípio de manutenção

O projeto foi mantido propositalmente simples: HTML estático, Sass/CSS e JavaScript nativo. Antes de introduzir framework, gerador de site ou backend, avalie se o ganho de manutenção compensa a complexidade adicional e registre a decisão.
